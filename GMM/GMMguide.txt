================================================================
  GMTC Simulator — GMM Transform Coding RD Curve Generator
================================================================

파일 구조
---------
  simulation.py                 실행 파일 (메인)
  main_optimal.py               quantizer 인프라 (simulation.py가 import)
  main.py                       GMM 인프라 (EM, MAP, transform 등)
  generate_custom_gmm_data.py   테스트용 GMM 데이터 생성기
  requirements.txt              Python 패키지 목록


환경 설정
---------
  Python 3.9 이상 필요.

  1) PyTorch 설치 (GPU 사용 시 CUDA 버전에 맞게):
     https://pytorch.org/get-started/locally/

     CPU만 사용할 경우:
       pip install torch --index-url https://download.pytorch.org/whl/cpu

  2) 나머지 패키지 설치:
       pip install -r requirements.txt


데이터 준비
-----------
  입력 데이터는 (T, N) shape의 2D 배열.
    T = 샘플 수 (최소 ~200 이상)
    N = 벡터 차원

  지원 포맷:
    .npy   numpy 배열
    .pt    torch 텐서
    .npz   numpy archive (key: 'data', 'x', 'X', 'train' 중 하나, 또는 첫 번째 배열)

  테스트용 데이터 생성:
    python generate_custom_gmm_data.py
    -> custom_gmm_data.npy 생성 (25000 samples, N=32, K=4)

    옵션:
      --N 16          차원
      --K 3           GMM component 수
      --T 30000       샘플 수
      --mean_scale 2  component 간 평균 거리
      --out data.npy  출력 파일명


실행
----
  기본 실행:
    python simulation.py --data custom_gmm_data.npy --K 4

  주요 옵션:
    --data PATH       입력 데이터 파일 경로 (필수)
    --K 4             GMM component 수 (데이터에 맞게 설정)
    --em_iter 50      EM 반복 횟수
    --gamma_min 1e-3  gamma sweep 하한
    --gamma_max 10.0  gamma sweep 상한
    --num_gamma 25    gamma sweep 포인트 수
    --train_ratio 0.8 train/test 분할 비율
    --seed 42         랜덤 시드
    --save out.png    결과 그래프 저장 경로 (기본: rd_custom.png)


출력
----
  RD curve 그래프 (PSNR vs bpp):
    - Theoretical RD (EM params)    이론적 bound (reverse waterfilling)
    - EM + MAP labels               실제 quantize/dequantize operational
    - Single Gaussian (no label)    K=1 baseline (GMM 안 쓸 때)

  Theoretical이 가장 위 (best), Single Gaussian이 가장 아래 (worst).
  EM curve가 Theoretical에 가까울수록 quantizer가 잘 동작하는 것.


예시
----
  # 기본 (N=32, K=4)
  python generate_custom_gmm_data.py
  python simulation.py --data custom_gmm_data.npy --K 4

  # 다른 설정 (N=16, K=3)
  python generate_custom_gmm_data.py --N 16 --K 3 --out data_16d.npy
  python simulation.py --data data_16d.npy --K 3

  # sweep 범위 조정
  python simulation.py --data custom_gmm_data.npy --K 4 --gamma_min 0.01 --gamma_max 20 --num_gamma 40

  # 합성 데이터 모드 (oracle curve 포함)
  python simulation.py --use_synthetic_data --K 4


참고
----
  - 첫 실행 시 quantizer_table.npz가 없으면, quantizer_table.npz가 자동 생성됨 (약 10초 소요, 이후 캐시)
  - GPU가 없어도 실행 가능 (CPU에서 동작)
  - EM 수렴이 느리면 --em_iter 를 늘려볼 것
